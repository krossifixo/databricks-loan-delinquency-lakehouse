# Data Dictionary — Raw Landing Zone

All data is **synthetic** (generated by `data/generate_data.py`, seed 42). No real customer data.

## `loans.csv` — loan origination master (one row per loan)

| Column | Type | Description |
|---|---|---|
| loan_id | string | Unique loan identifier (`LN000001`). Primary key. |
| origination_date | date | Date the loan was originated. |
| product_type | string | `new_auto`, `used_auto`, or `refi_auto`. |
| principal_amount | decimal | Original financed amount (USD). |
| apr | decimal | Annual percentage rate (fraction, e.g. 0.0717). |
| term_months | int | Loan term in months (48/60/72/84). |
| monthly_payment | decimal | Amortized scheduled monthly payment (USD). |
| fico_band | string | Borrower FICO band at origination. |
| borrower_monthly_income | decimal | Gross monthly income (USD). |
| dti_ratio | decimal | Debt-to-income ratio (0-0.75). |
| ltv_ratio | decimal | Loan-to-value ratio (auto can exceed 1.0). |
| state | string | US state (2-letter). |

## `payments.csv` — monthly payment-history snapshots (12 per loan)

| Column | Type | Description |
|---|---|---|
| loan_id | string | FK to `loans.loan_id`. |
| as_of_month | date | Snapshot month. |
| scheduled_payment | decimal | Amount due that month. |
| actual_payment | decimal | Amount actually paid (0 when missed). |
| outstanding_balance | decimal | Remaining principal at snapshot. |
| days_past_due | int | 0, 30, 60, 90, or 120. |
| delinquency_bucket | string | `current` or `<n>dpd`. |

## Derived target (computed downstream, not in raw)
`target_delinquent_next` = 1 if a loan that is **current** this month rolls to **30+ DPD next month**, else 0. This is the ML prediction target: catch at-risk current loans before they roll.
